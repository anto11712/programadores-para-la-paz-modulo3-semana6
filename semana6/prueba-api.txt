Al enviar una petición POST a http://localhost:3000/registro con el JSON
{"nombre": "Maria", "mensaje": "Hola comunidad"}, el servidor responde:

{"estado":"Datos recibidos","nombre":"Maria","mensaje":"Hola comunidad"}

Esto confirma que express.json() permitió leer correctamente los datos
enviados en req.body y que el servidor los devolvió tal como se esperaba.
